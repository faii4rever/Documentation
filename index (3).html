Faii — AI Chat adalah aplikasi chat untuk developer. Masukkan Base URL + API Key, langsung terhubung ke model favoritmu. Upload file, generate PDF, sampai arsip ZIP — semua dari satu tempat.

Buka aplikasi Baca panduan
Groq · Qwen (default) OpenAI Anthropic PDF · ZIP
01 — Fitur

Fitur

Daftar fitur yang ada di app saat ini. Sebagian besar berjalan langsung tanpa perlu setting tambahan.

  • Upload image

    Kirim gambar ke AI untuk dianalisis langsung di chat.

  • Upload file

    Lampirkan file apa pun ke dalam percakapan.

  • Atur bahasa

    Ganti bahasa antarmuka sesuai preferensimu.

  • Support PDF

    Kirim dan proses dokumen PDF di dalam chat.

  • Support ZIP

    Kelola file terkompresi langsung dari percakapan.

  • Generate file / ZIP

    Bikin file atau arsip ZIP dari hasil AI, siap dipakai di project-mu.

  • Generate PDF

    Ekspor hasil kerja menjadi dokumen PDF yang rapi.

  • Preview

    Menampilkan tampilan hasil code HTML secara langsung.

  • Salin kode

    Copy blok kode dari jawaban AI dengan satu klik.

  • Download file / ZIP

    Unduh file atau arsip hasil generate ke perangkatmu.

  • Support OpenAI & Anthropic

    Kompatibel dengan dua provider AI besar.

  • Model default Groq (Qwen)

    Sudah ada model bawaan — bisa langsung dipakai tanpa konfigurasi.

02 — Panduan

Cara memasang AI

Tiga langkah singkat. Setelah ini, app langsung bisa dipakai.

Buka menu

Klik tombol garis tiga ☰ di pojok kiri atas layar.

Masuk ke Setting

Pilih menu Setting dari daftar yang muncul.

Atur kredensial

Isi Nama AI, Base URL, dan API Key di sana. Selesai — AI siap dipakai.

03 — Kesimpulan

App ini dibuat dengan satu tujuan: mempermudah developer memakai AI cukup bermodalkan Base URL + API Key. Tanpa langkah rumit, tanpa konfigurasi nguli.
